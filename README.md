# Isle of Glass website

Public marketing, support and privacy website for the in-development iPhone game. This repository contains only the static website and approved public game images. It does not contain the iOS app source, signing material, credentials, provisioning profiles or a hosted game backend.

Serve locally with `python3 -m http.server 8080`, then open `http://localhost:8080`.

GitHub Pages publishes the `main` branch root. No analytics, forms, remote scripts, build dependencies or cookies are added by this site. GitHub hosting has its own privacy practices.

The site deliberately does not promise a release date, App Store approval, a completed thousand-puzzle campaign or a live hosted community. Reconcile copy and privacy disclosures with verified implementation before changing those claims.

Game imagery remains the project owner's content; making this website repository public does not grant a separate license to reuse it. GitHub Issues is the public support channel. Security vulnerabilities use private vulnerability reporting. Do not post sensitive personal information in issues.
