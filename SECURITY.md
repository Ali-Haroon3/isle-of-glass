# Security reports

Please use this repository's **Report a vulnerability** action for security defects: https://github.com/Ali-Haroon3/isle-of-glass/security/advisories/new

Do not publish exploit details, account tokens, personal data or credentials in public issues. Include enough information to reproduce the issue without accessing another person's data. Do not test against other users' accounts or disrupt services.

Private vulnerability reporting is for security defects. It is not a general private support or privacy-request inbox. Ordinary non-sensitive support belongs in GitHub Issues. The hosted game community is not publicly available yet.

No response-time guarantee is made by this document. Reports need review by the maintainer.
