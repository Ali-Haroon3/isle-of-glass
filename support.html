Questions, bugs, privacy, or a safety concern? Send a private request to the developer without creating an account.

Send a private request ↗Browse existing reports

Private support gives you a code to save so you can read a reply or delete your request. GitHub issues are public and require a GitHub account. Never post passwords, tokens, private messages, personal information or someone else’s data.

What helps with a bug report?

Include your iPhone model, iOS version, app version, puzzle name and the steps that led to the issue. Describe what you expected and what happened. A screenshot can help, after you remove any personal information.

How do I make a piece?

Choose Shape and drag through neighboring squares. Start on empty glass to create a new piece, or inside a piece to extend it. Each piece must follow the rule card, and every playable square must be filled. Cut mode draws seams instead.

Can I try a different solution?

Yes. Use Undo, Redo or Restart to explore. Colors are cosmetic, and every valid solution is accepted. Earned island progress stays earned when you replay a puzzle.

Where is my progress?

The campaign saves on your device. If a save error appears, keep the app open and use Retry. Don’t delete the app to troubleshoot: that removes local data. The game does not automatically synchronize progress between devices.

How do I remove my data?

In the app’s Settings, use Delete all local game data to remove campaign progress, Workshop records and preferences. Reset island progress only removes the campaign. Community → Profile → Delete community profile removes the server profile and submissions. Delete support requests separately using their private codes. Exported files and existing device backups are managed separately. Read the privacy policy for details.

Community safety and unwanted puzzle files

Use Report on a community mosaic to send a private concern to moderation. Block creator hides their online mosaics and known downloaded copies; unblock them from your community profile. New submissions stay pending until reviewed. For an appeal or rights concern, use private support. Remove an imported puzzle from your Workshop. You can also block that specific puzzle file from being imported again. This is not a block on a person. If reporting a file through a public issue, describe the problem without sharing personal or harmful content.

Security vulnerabilities

Please use private vulnerability reporting for a security defect. Do not publish exploit details or sensitive information in a public issue. This channel is for security reports, not a general private support inbox.

About this project

Isle of Glass is maintained by Ali Haroon. It is available free for iPhone on the U.S. App Store, with no ads, subscriptions or paid hints. iOS 17 or later is required.
