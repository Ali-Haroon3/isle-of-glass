This policy describes the current local development build of Isle of Glass and this public website, maintained by Ali Haroon.

The game is not publicly released. An online community is being developed but is not publicly available. This policy will be updated with its actual data practices before those services are offered.

What stays on your device

The current game stores puzzle boards, completed puzzles, preferences and Workshop records on your iPhone. It does not require an account or automatically send these game records to the developer. The campaign works offline.

No advertising or tracking SDKs

The current build includes no advertising or third-party analytics SDKs. It does not track you across other apps or websites. It does not request access to your camera, microphone, contacts, location, photo library or advertising identifier.

Files you choose to share

Exporting a Workshop puzzle uses the iPhone’s system share sheet or file picker. You choose the destination. A puzzle file contains its rules, board geometry and example solution. The selected app or service handles the file under its own policy. Importing reads the file you select; it does not give the game access to all your files.

Backups and deletion

iOS or iCloud backups may include local game data depending on your settings. Isle of Glass does not provide its own cloud synchronization in this build. Delete all local game data in Settings removes local game records and preferences. Deleting the app also removes its local container. Neither action recalls shared copies or removes existing backups; manage those through the destination service or Apple’s settings.

This website

This site uses no analytics scripts, advertising, tracking pixels, sign-up forms or site cookies. It is hosted by GitHub Pages. GitHub processes technical request information to provide its services; see GitHub’s privacy statement. We do not receive your local game progress through a visit to this site.

Support you choose to request

Support is currently offered through GitHub Issues. Reports and your GitHub profile are public. The maintainer uses the information you choose to provide to investigate and respond. Avoid posting sensitive information. GitHub manages its own account data, retention and privacy controls.

If you need a public report corrected or removed, use the report’s thread without adding private information. For your GitHub account data, use GitHub’s privacy controls. Security vulnerabilities can be reported using private vulnerability reporting; that is not a general privacy-request inbox.

Future online services

Account creation, hosted puzzles or other online features will require clear information about what is collected, why, how long it is retained, and how to delete it. Those details and a suitable private contact channel will be published before enabling such services. This policy makes no claim that an unannounced service is already operating.

Questions

For non-sensitive questions about this policy, visit the support page or contact the maintainer through the project’s public GitHub issues. The current game has no developer-held player account or game-save database to delete.
